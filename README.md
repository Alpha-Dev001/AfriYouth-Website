# AfriYouth Innovation Labs

A research, innovation, and policy consulting platform that identifies, nurtures, and advances promising ideas from Africa's young innovators to address the Sustainable Development Goals.

## Tech stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Motion (Framer Motion) + GSAP

## Getting started

### Prerequisites

- Node.js 20+

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The app will be available at http://localhost:3000.

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

### Tests

```bash
npm test
```

### Type check

```bash
npm run lint
```
